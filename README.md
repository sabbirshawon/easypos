# EasyPOS

**Author:** Sabbir Ahmed  
**Project URL:** [https://easypos.vercel.app](https://easypos.vercel.app)

A **simple and efficient Point of Sale (POS) system** built with **Next.js 16, React 19, TypeScript, and Tailwind CSS**. EasyPOS allows users to:

- Add products with price and quantity  
- Edit product names and quantities  
- Apply discounts and taxes  
- Generate and print receipts  
- Edit company name, tax, and items directly on the receipt  

---

## Features

- **Dynamic Cart:** Add, edit, and remove products  
- **Discount & Tax:** Apply percentage discounts and custom taxes  
- **Receipt Generation:** View, edit, and print receipts  
- **Client-Side Rendering:** Fixes hydration issues with SSR  
- **Responsive Design:** Works on desktop and mobile  

---

## Tech Stack

- **Frontend:** React 19, Next.js 16  
- **Styling:** Tailwind CSS 4  
- **Icons:** Lucide React  
- **TypeScript** for type safety
